## Objetivo

Não esquecer a inscrição no exame oficial.

## Tarefa

Este exercício é administrativo no subject original. Quando estiver inscrito no evento **e** no projeto Exam00, crie `INSCRICAO.md` com exatamente estas duas linhas:

```text
evento: ok
projeto: ok
```

Na piscina, faça isso no primeiro dia; sem inscrição você não pode fazer o exame.

## Protótipo

```text
INSCRICAO.md
```

## Exemplo

```text
cat INSCRICAO.md
evento: ok
projeto: ok
```

## Dica

O calendário e o projeto aparecem separados na intranet. Confirme os dois.

## Erros comuns

- Inscrever-se só no evento e esquecer o projeto.
- Deixar para a última hora.
