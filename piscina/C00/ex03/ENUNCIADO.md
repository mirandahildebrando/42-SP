## Objetivo

Imprimir os dígitos de 0 a 9.

## Tarefa

Escreva uma função que mostre os dígitos de 0 a 9, em ordem.

## Protótipo

```c
void ft_print_numbers(void);
```

## Exemplo

```text
ft_print_numbers();  ->  0123456789
```

## Dica

Comece em `'0'` e vá até `'9'`.

## Erros comuns

- Confundir o caractere `'0'` com o número 0.
- Usar `printf`.
